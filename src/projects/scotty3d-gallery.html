Background Info

This is my own implementation of Scotty3D, a 3D graphics software package, as part of self-studying introductory computer graphics. For studying, I followed the lectures from CMU 15-462's Fall 2020 offering while completing the assignments from the Spring 2026 version. To maintain academic integrity, the source code is kept private, but I have shared some of my renders below.

The assignment is divided into four main parts:

  • A1 — Rasterizer: CPU rasterizer (mostly) from scratch, with features including supersampling, perspective-correct interpolation, mipmapping, and so on.
  • A2 — Mesh Editing: Mesh-modeling operations with a half-edge data structure, both local operations (edge flips, splits, etc.) and global operations (triangulation, subdivision, etc.)
  • A3 — Path Tracing: Physically-based CPU path tracer (mostly) from scratch, with features including BVH acceleration, BSDF material modeling, environment light-mapping, and so on.
  • A4 — Animation: In Progress
